# 制作基準（官兵衛用）

毎日投稿の動画は、たまさんに何も言われんでも出せる品質で作る。次の官兵衛もこの基準を守ること。

## 絶対に守ること

- 使う事実は「紹介会社に確認済み」のものだけ（CLAUDE.md の引き継ぎメモ参照）。言い換えで意味を盛らない
- 字幕（動画の中）では「Amazon」と言わない。「配送の仕事」と言う。Amazonの名前は見出しと投稿文だけ
- 金額が出る動画は、画面と投稿文の両方に注意書き（ツールが自動で入れる）
- 投稿文に「全国対応OK！」「基本は関東エリアの情報です。」の2行。全国に触れるのはここだけ
- ハッシュタグは5個まで（ツールがチェック）
- 「この動画はAIで作っています」は投稿文の最後（ツールが自動で入れる）。「VOICEVOX:玄野武宏」は画面に出す（自動）

## 全体の設計（①〜⑩）

`funnel/FUNNEL.md` が設計図。動画は「③認知 → ④比較 → ⑥商談」のどこを担当するかを決めてから作る。
1週間の割り振り（木・金＝認知／土・日・月＝比較／火＝認知を広げる／水＝商談）と、最後のお願い（フォロー／保存／DM）は FUNNEL.md の表どおり。
台本の先頭に `# ファネル：③顧客認知／CTA：フォロー` のように書いておく。
使わなかった台本は `scripts/stock/` に置いて、次の週以降に回す。

## 台本の作り方

1. **1行目はつかみ**。見る人（人間関係に疲れて、ひとりで働きたい20〜30代の男性）が「自分のことや」と思って指を止める一言。疑問形か「知ってますか？」型
2. 2〜5行目で答えと中身。1行は短く（40字くらいまで）。ツールが「ひと息」ごとに字幕を切り替える
3. 「3つの理由」「こんな人に」みたいな並べる型は `label:` を使う（「理由1」などのバッジが出る）
4. 最後の行は行動のお願い（固定投稿へ／DMで相談）
5. 型を毎日変える：よくある質問／3つの理由／こんな人に／向いてる・向いてない／正直なお金の話／相談の流れ
6. 同じ週に同じネタをかぶらせない。投稿済みは `scripts/posted/` を見て確認する
7. VOICEVOXの読み間違いは `yomi:` で直す（例：個人事業主 →「個人じぎょうぬし」）。作ったら `audio_query` の kana で読みを確認する

## 投稿文の型

```
（1行目：動画のつかみと同じ一言）

（中身を2〜3行）

✅ （確認済みの条件を2つくらい）

全国対応OK！
基本は関東エリアの情報です。

📌 くわしい条件はプロフィールの固定投稿へ
💬 DMで「相談したい」と送ってください
🔖 あとで見返せるように保存がおすすめです

#（5個まで）
```

## 動画の見た目（ツールが自動でやる）

- 背景は5色を順番に回す。斜めのしま模様がゆっくり流れる
- 1行目は濃い紺の枠に大きい字。大事な言葉と数字は色を変える（`emphasis:` で追加もできる）
- 字幕はポンッと飛び出す。セリフが変わるとはこぶがぴょんと跳ねる。しゃべると口が動く、まばたきする
- 上に進み具合のバー。最後の2秒は「条件は／プロフィールの／固定投稿へ」＋「名前をタップ」の矢印
- BGMと効果音はプログラムで作る（著作権ゼロ・無料）。声の間はBGMが自動で小さくなる。音量はスマホ向けにそろえる

## 毎週の流れ

1. 7本ぶんの台本を `scripts/` に書く（`01_〜07_`）
2. `./start_voicevox.sh` → `python3 make_videos.py --preview` で見た目を確認 → `python3 make_videos.py`
3. 1本でも見て、音・字幕・読みをチェック（フレームを抜き出して確認）
4. 保存用ページを作る：
   `python3 make_download_page.py --start 翌日の日付 --time 20:00 --dir （作業フォルダ） output/今週の動画...`
   → Artifact に index.html と動画を一緒に publish_files し、downloads を宣言（既存ページの更新なら slug を使う）
5. ストーリー画像（毎日の告知7枚）も作る：`python3 make_stories.py --start 翌週木曜の日付` → `make_download_page.py --dir` で別ページにして Artifact で公開（downloads 宣言）
6. 投稿が済んだ台本は `scripts/posted/` へ移す
7. CLAUDE.md の引き継ぎメモを更新して、コミット＆プッシュ

## 競合リサーチ（2026年11月12日、インスタ「軽貨物ドライバー」検索）

伸びている型（再生数）と、うちでの使い方。新しい週の台本はここから型を選ぶ。

| 型 | 例（再生数） | うちで使えるか |
|---|---|---|
| 手取り・月収の発表 | 「12月の手取り額を発表」235万／「手取り額を発表」121万／「月収いくらですか？」481万 | 収入の数字が確認できたら最優先 |
| 年齢×経歴×結果 | 「21歳で高卒なのに同年代より稼げてて今これ」66.2万 | 実際に働き始めた人の声（⑨口コミ）が集まったら |
| 強い否定・本音 | 「やめてください！」75.2万／「働かないほうがいい理由」16.1万／「ガチで稼げないよ」16万／「絶対やめておけ」 | ⭕ 正直路線と相性がいい。確認済みの事実（車代・ガソリン代がかかる等）で作る |
| 質問に答えますシリーズ | 「配送中ってずっと1人なんですか？」「女性ドライバーでも働けますか？」 | ⭕ 同じ見た目のシリーズにして毎週続ける。「ずっと1人？」は確認済み（上司も同僚もいない、ひとりで黙々） |
| 黒帯タイトルのシリーズ | 「軽貨物『経費を引くと…』」のように毎回同じ枠 | ⭕ シリーズ感で「また見たい」を作る |
| 人間関係の悩み | 「人間関係ダルすぎる」 | ⭕ うちの一番の売りど真ん中 |
| 社会の話 | 「日本の物流がストップします」47.3万 | △ 事実の裏づけが要るので慎重に |
| 2択 | 「あなたならどっち？究極の2択」 | ⭕ コメントが増えやすい |

競合のプロフィールの共通点：ハイライト（work/recruit/Q&A）、数字（平均年収など）、応募はDMかLINE。
