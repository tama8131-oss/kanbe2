# DM・コメント返信テンプレ集（⑥商談〜⑩紹介）

使っているのは、紹介会社に確認済みの事実だけ。
【要確認】がついている文は、紹介会社に確認してから使う。

---

## ⑥ 商談

### A. 「相談したい」とDMが来たとき（最初の返事）

```
DMありがとうございます！はこぶです。
相談に乗る前に、3つだけ教えてください。

1. 住んでいる地域（都道府県・市区町村）
2. 車を持っているか（持っていなくても、車は貸してもらえます）
3. いつごろから働きたいか

わかったら、くわしい条件を案内します。
```

### B. コメントに「相談」と書いてくれた人へ（DMで送る）

```
コメントありがとうございます！はこぶです。
条件をお送りしますね。

✅ 経験ゼロでOK
✅ 上司も同僚もいない、ひとりで黙々
✅ 車がなくても、貸してもらえる（車レンタルは持ち帰れる）
✅ 外国籍もOK（個人事業主として働けるビザがある人）
✅ 全国対応OK（基本は関東エリアの情報です）

くわしく案内するために、3つだけ教えてください。
1. 住んでいる地域
2. 車を持っているか
3. いつごろから働きたいか
```

コメント欄への返信（ほかの人にも見えるように）

```
DMお送りしました！確認してみてください📩
```

### C. 3つ答えてくれたあと（条件の案内）

```
ありがとうございます！
お話を聞いた内容で、条件を案内しますね。

・Amazon配送の仕事（業務委託）です
・経験ゼロでOK、上司も同僚もいない、ひとりで黙々と働けます
・車がない場合は、車を貸してもらえます（持ち帰れます）

お金のことも正直にお伝えします。
車を借りる場合、関東の例で
・車代＋最上位の保険：月7万6,000円
・ガソリン代：月約3万円
がかかります。

ここまで読んで、進めてみたいと思ったら「進めたい」と返事をください。
質問があれば、なんでも聞いてください。
```

### D. よくある質問への返事

経験がなくて不安

```
経験ゼロでOKです！配送の仕事をしたことがない人でも始められます。
```

車を持っていない

```
大丈夫です。車がなくても、車は貸してもらえます。借りた車は持ち帰れます。
ただし、車代とガソリン代はかかります（関東の例：車代＋最上位の保険で月7万6,000円、ガソリン代が月約3万円）。
```

人間関係が心配

```
上司も同僚もいない、ひとりで黙々と働ける仕事です。
```

外国籍

```
外国籍もOKです。ただし、個人事業主として働けるビザがある人に限ります。
お持ちのビザで個人事業主として働けるか、先に確認をお願いします。
```

関東以外に住んでいる

```
全国対応OKです！お住まいの地域を教えてもらえたら、案内します。
```

いくら稼げるか聞かれたとき（収入の数字は確認中なので、言い切らない）

```
収入は、働く日数・時間・配達件数などによって、人によって大きく変わります。
お住まいの地域と働き方に合わせて、目安をお伝えできるように確認しますね。
```

## ⑧ 成約（紹介会社につなぐとき）

本人の同意をとる

```
進めたいとのこと、ありがとうございます！
ここから先は、紹介先の会社とのやりとりになります。
お名前と連絡先を、紹介先の会社にお伝えしてもいいですか？
```

紹介会社に伝えることのチェック表（たまさん用）

- お名前
- 連絡先
- 住んでいる地域
- 車を持っているか（借りる希望か）
- いつごろから働きたいか
- 外国籍の場合：個人事業主として働けるビザがあるか

【要確認】紹介会社にどうやって伝えるか（フォーム／LINE／電話など）、面談はあるか、始めるまで何日くらいか

## ⑨ 口コミ（働き始めた人へ。1〜2週間後）

```

よかったら、正直な感想を教えてください。
いいことも、大変なことも、どちらでも大丈夫です。
```

```

もちろん、断ってもらっても大丈夫です。
```

## ⑩ 紹介（働き始めた人へ。慣れてきたころ）

```
はこぶです！いつもありがとうございます。
もし、まわりに「人間関係に疲れてる」「ひとりで働きたい」という人がいたら、このアカウントを教えてもらえるとうれしいです。
相談だけでも大丈夫なので、気軽にDMくださいと伝えてください。
```

【要確認】紹介してくれた人へのお礼（紹介料など）があるかどうか。確認できるまで、お礼の話はしない。
