# 集客〜紹介の設計図（①〜⑩）

ゴール：働く人を、早く・たくさん紹介する（お金はかけない）。
見る人：人間関係に疲れて、ひとりで働きたい20〜30代の男性（関東中心）。

| 段階 | やること | 中身・道具 | 測る数字 |
|---|---|---|---|
| ①プロダクト | 「何を提案するか」をはっきりさせる | 一番の売り：**上司も同僚もいない、ひとりで黙々**。それを支える条件：経験ゼロでOK／車がなくても貸してもらえる（持ち帰れる）／外国籍もOK（個人事業主として働けるビザがある人）／全国対応OK（基本は関東）。弱み（車代・ガソリン代）は隠さず先に言う | ― |
| ②広告（無料） | 毎日20時にリール1本。同じ動画をTikTok・YouTubeショートにも出す | `make_videos.py`（毎週火曜に7本を自動で作る） | 1本あたりの再生数 |
| ③顧客認知 | 1秒目のつかみで指を止める。はこぶのキャラで「また見たい」と思わせる | 認知用の動画：つかみ重視、最後は「フォロー」をお願いする | フォロワー数、最後まで見た割合 |
| ④顧客比較 | ほかの仕事と比べている人に、判断の材料を渡す | 比較用の動画：お金の話、向いてる・向いてない、3つの理由。最後は「保存」をお願いする。正直に言うことで信用をとる | 保存数 |
| ⑤LPやHP | プロフィールのリンクに、条件・お金・流れ・FAQを1枚にまとめたページを置く | `make_lp.py` → `lp/index.html`（tiiny.site に無料で置く）。FAQはAI検索にも読まれる形にしてある | リンクのタップ数 |
| ⑥商談 | DM・コメントで相談を受けて、3つ聞いて条件を案内 | 商談用の動画（相談の流れ）＋ `dm_templates.md` のA〜D | DMの数、案内まで進んだ数 |
| ⑦リマインド | 返事が止まった人に1日後・3日後・7日後に1回ずつ。フォロワーには毎日の動画 | `dm_templates.md` の⑦ | 再開した数 |
| ⑧成約 | 本人の同意をとって紹介会社につなぐ | `dm_templates.md` の⑧（チェック表） | 紹介した人数 |
| ⑨口コミ | 働き始めた人の正直な感想を、同意をとって名前を出さずに動画にする | `dm_templates.md` の⑨ → 「始めた人の声」動画 | 集まった感想の数 |
| ⑩紹介 | 働き始めた人に、まわりの人を紹介してもらう | `dm_templates.md` の⑩ | 紹介経由の相談数 |

## 1週間の動画の割り振り（毎日20時）

| 曜日 | 段階 | 型の例 | 最後のお願い |
|---|---|---|---|
| 木 | ③認知 | つかみ一発（上司も同僚もいない など） | フォロー |
| 金 | ③認知 | よくある質問（経験ゼロ など） | フォロー |
| 土 | ④比較 | 正直なお金の話 | 保存 |
| 日 | ④比較 | 向いてる人・向いてない人 | 保存 |
| 月 | ④比較 | 3つの理由 | 保存 |
| 火 | ③認知（広げる） | 外国籍・車なし など、別の層に向けた質問 | DM |
| 水 | ⑥商談 | 相談の流れ・DMのハードルを下げる | DM |

働き始めた人の感想（⑨）が集まったら、毎週1本を「始めた人の声」に入れ替える。

## 毎週ふり返ること

- 再生数が一番多かった動画のつかみ → 次の週の認知用に、同じ型で別のネタを作る
- 保存が多かった動画 → 比較用の型を増やす
- DMが来た日の動画 → 商談用の言い方を増やす
- 数字が取れないところ（リンクのタップ・DM数）は、たまさんにインサイト画面のスクショを週1回もらって確認する
