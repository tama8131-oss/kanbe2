# ショート動画 自動作成ツール（Amazon配送ドライバー募集用）

インスタ（リール）と TikTok 用の縦長動画（1080×1920、mp4）を、
台本ファイルからまとめて自動で作る道具やで。

- お金は0円（無料のものだけ使ってる）
- 声は VOICEVOX（玄野武宏）、映像も全部AIで作る
- 投稿は自動ではせえへん。できた動画を携帯で確認してから、各アプリの予約投稿で手動で出してな

---

## いちばんカンタンな使い方（官兵衛にお願いする）

パソコンの操作が苦手でも大丈夫。Claude Code（官兵衛）に話しかけるだけで作れるで。

### 手順1：台本をそろえる

作りたい動画の台本を、官兵衛に伝える。
（例：「よくある質問の型で『雨の日はどうするの？』の動画を作りたい」）

官兵衛が `video_tool/scripts/` に台本ファイル（YAML）を作るで。

### 手順2：官兵衛にこう頼む

````
video_tool の README のとおりに準備して、scripts の台本を全部動画にして
````

官兵衛が裏で、準備（VOICEVOX の用意など）→ 動画作り、を全部やってくれる。
初回は準備に5〜10分くらいかかるで。

### 手順3：できた動画を確認する

`video_tool/output/` に、次の2つができる。

| できるもの | 中身 |
|---|---|
| `20261110_01.mp4` | 動画（日付_番号） |
| `20261110_01.txt` | 投稿文（そのままコピペで使える） |

官兵衛に「できた動画をGitHubに上げて」と頼めば、携帯から見られるようになるで。

### 手順4：携帯で確認して、予約投稿する

1. 動画を携帯に保存する
2. 中身に間違いがないか、自分の目で確認する
3. インスタ・TikTok のアプリで動画を選ぶ
4. `.txt` の投稿文をコピーして、説明欄に貼る
5. 予約投稿の日時を決めて、予約する

## 台本（YAML）の書き方

`scripts/` の中に、**動画1本につき1ファイル**作る。
見本は `scripts/faq_kuruma_nashi.yaml`。これをコピーして書きかえるのがラクやで。

```yaml
type: よくある質問          # 型（稼ぎ解説 / 1日の流れ / よくある質問 / 正直なデメリット）
title: 車がなくても始められる？
lines:                      # セリフ。1つずつ字幕が切り替わる
  - text: "よくある質問。車を持っていなくても、配送の仕事は始められる？"
  - text: "関東で、会社の車を借りる場合の例です。"
    table:                  # 数字の表（いらんときは書かない）
      title: "毎月かかるお金"
      rows:
        - ["車代＋最上位の保険", "月7万6,000円"]
        - ["ガソリン代", "月約3万円"]
      note: "※関東・会社の車を借りる場合の例"   # どの地域・どの条件か（必ず書く）
caption: |
  ここに投稿文を書く
  （何行でもOK）
```

### もっと見せ方を変えたいとき

- `label: "理由1"` を書くと、字幕の左上にバッジが出る（3つの理由・こんな人に、などで使う）
- `emphasis: ["言葉1", "言葉2"]` を書くと、その言葉の色が変わって目立つ（数字と、よく使う大事な言葉は自動で目立つ）
- `theme: 0`〜`4` で背景の色を選べる（書かなければ自動）
- 作り方の基準は `PRODUCTION.md` にまとめてある

### 書くときの約束ごと

- **セリフや数字は `"` と `"` で囲む**（囲まんと数字が勝手に変わることがあるから、ツールが止めて教えてくれる）
- 字下げ（行の頭のスペース）は、見本と同じにそろえる
- 表の **一番下の行は「合計」として濃い色** になる。合計の行がない表のときは `highlight_last: false` を書く
- 表を出すときは `note`（どの地域・どの条件の例か）を**必ず書く**。書き忘れたらツールが止まって教えてくれる
- `type: 1日の流れ` にすると、画面に「再現」と出る
- 投稿文のハッシュタグ（#〜）は**5個まで**（インスタの決まり。6個以上やとツールが止まって教えてくれる）
- 声の読み方がおかしいときだけ、`yomi: "読ませたい文"` を足す（画面の字幕は `text` のまま）

### ツールが自動でやってくれること

- 右上に「AI生成」、左上に「Amazon配送ドライバーのリアル」を表示
- 下にキャラ「はこぶ」を表示（ゆらゆら動いて、しゃべると口が動いて、ときどきまばたきする）
- 動画ごとに背景の色を変える（5色を順番に回す。YAML に `theme: 0`〜`4` を書けば色を選べる）
- 1行目のセリフ（つかみ）は、大きい字と濃い色の枠で目立たせる
- 最後の2秒に「条件は／プロフィールの／固定投稿へ」を表示
- **金額が出る動画**（表があるか「円」が入っている動画）には、画面と投稿文の両方に注意書きを自動で入れる
- 画面の右下に、声のクレジット「VOICEVOX:玄野武宏」を出す（VOICEVOXの決まりで、どこかに必ず表記が必要。投稿文には書かない）
- 投稿文の最後に、必ずこの1行を入れる
  ```
  この動画はAIで作っています
  ```
- 台本の文字・数字は、1文字も変えずにそのまま使う

## 数字のルール（大事）

使ってええのは **紹介会社に確認できた本物の数字だけ**。

**使ってよい数字（関東・会社の車を借りる場合の例）**

- 車代＋最上位の保険：月7万6,000円
- ガソリン代：月約3万円
- 合計：月約10万6,000円

**使ってよい条件（紹介会社に確認済み）**

- 経験ゼロでOK
- 車がなくても、貸してもらえる
- 車レンタルは持ち帰れる
- 上司も同僚もいない、ひとりで黙々
- 全国どこでも働ける（書くときは「全国対応OK！基本は関東エリアの情報です」）
- 外国籍もOK（個人事業主として働けるビザがある人）

**まだ使わない（紹介会社に確認中）**

- 東京・自分の車の場合の月の目安（平均 約46万7,000円／稼ぐ人 約60万7,000円）
  - ガソリン代を引く前か後か、税金・保険料が引かれているかが分からないため
- 会社の車を借りる場合の、車代・ガソリン代を引いた後の額
- 「経費を引いた後 平均 約22万1,000円」「多い人 37万9,000円／38万円」（どこの地域の数字か分からないため）
- 沖縄の金額
- 「休みの日も車に乗ってOK」（「持ち帰れる」は確認済みやけど、休みの日に乗ってええかは未確認）
- 自分の車の場合の、車検・保険などの費用

そのほか：
- キャラには「Amazon」と書かない（公式の募集とまちがわれるから）
- 相談はインスタのDMで受け付ける（個人のLINEは使わない）
- 投稿文には次の2行を書く（全国対応はこの1行だけ。ほかは関東エリアの情報にする）
  ```
  全国対応OK！
  基本は関東エリアの情報です。
  ```

## 自分で動かすとき（Linux の黒い画面）

官兵衛に任せず自分で動かす場合の手順。1行ずつ入力して Enter を押してな。

### 1. このフォルダに移動する

```
cd video_tool
```

### 2. 準備する（はじめの1回だけ）

```
./setup_linux.sh
```

フォント、ffmpeg（動画を作る道具）、VOICEVOX（声を作る道具・約1.9GB）をそろえる。
数分かかるから、「準備おわり！」と出るまで待ってな。

### 3. VOICEVOX を起動する

```
./start_voicevox.sh
```

「VOICEVOX の準備ができました。」と出たらOK。

### 4. 動画を作る

```
python3 make_videos.py
```

`scripts/` の台本が全部、`output/` に動画になる。
1本だけ作りたいときは、こう打つ。

```
python3 make_videos.py scripts/faq_kuruma_nashi.yaml
```

### おまけ：声なしで見た目だけ確認する

```
python3 make_videos.py --preview
```

`output/preview/` に、画面の画像だけができる（VOICEVOX がいらんから早い）。

| 出てきた文 | どうする？ |
|---|---|
| VOICEVOX につながりません | `./start_voicevox.sh` を実行してから、もう一回 |
| フォントが見つかりません | `./setup_linux.sh` をもう一回 |
| ffmpeg が見つかりません | `./setup_linux.sh` をもう一回 |
| 〜が文字になっていません | その数字や文を `"` で囲む |
| table に note がありません | 表の下に `note:` を書く |

わからんときは、出てきた文をそのまま官兵衛に見せてな。

### 画面の決まり（変えたいときは `make_videos.py` の上のほう）

- 背景の色 RGB(220,235,245)、文字の色 RGB(35,57,91)
- フォント：Noto Sans CJK Bold
- 声：玄野武宏（ノーマル）、読む速さ 1.1
- 青山龍星は使わない（企業が関わる利用は事前確認が必要なため）
