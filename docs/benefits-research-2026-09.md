# 給付金・支援制度リサーチ（たま／弟）2026年9月時点

前提となる事実関係は `CLAUDE.md` の引き継ぎ記憶を参照。ここでは各制度を調べた結果と、
次に何をどう動かすかを書く。制度の細かい金額・要件は自治体や年金事務所の窓口で
最終確認が要る前提（【未確認】と明記した箇所は特に）。

## 1. たまの盤面：障害年金を「本命」から「具体的な手続き」に落とす

### 1-1. 障害年金の3要件（ここが全部揃わないと出ない）

1. **初診日要件**：障害の原因になった病気・ケガで初めて医師の診察を受けた日が特定できること
2. **保険料納付要件**：初診日の前日時点で、初診日の月の前々月までの被保険者期間のうち
   3分の2以上保険料を納めている（または直近1年間に未納がない）こと
3. **障害の状態要件**：障害認定日（初診日から1年6ヶ月後、または症状固定日）に、
   国が定める障害等級（1〜3級、基礎年金は1・2級のみ）に該当する状態であること

→ この3つのうち、たまのケースで一番効いてくるのが**初診日**。初診日によって
「どの年金制度に入っていたか」が決まり、もらえる年金の種類・額が変わる。

### 1-2. たまのケースで初診日が重要な理由

- 軟禁・暴行事件の後遺症（骨折痕・視力低下）と精神の診断書がベースになっている
- もし精神科の**初診日**が、静岡の警備会社に勤めていた期間（〜去年2月後半、厚生年金加入中）
  なら → **障害厚生年金**の対象になる可能性がある（基礎年金より額が高く、3級もあり、
  障害厚生年金には「配偶者加給年金」等はないが3級の最低保障額もある）
- 初診日が退職後（国民年金のみの期間）なら → **障害基礎年金**（1・2級のみ、金額は定額）
- なので「精神科の初診日はいつで、その時どの年金制度に入っていたか」を
  年金事務所の記録と診断書の両方で突き合わせる必要がある

**令和8年度の目安額**（1級・2級のみで金額は固定、厚生年金は別途上乗せあり）
- 障害基礎年金1級：年額 約105.9万円（月換算 約8.8万円）
- 障害基礎年金2級：年額 約84.7万円（月換算 約7万円）※1級の75%相当
- 精神・視力どちらも認定基準に該当すれば、併合認定でより上位の等級になる余地もある

→ 「月6〜8万」という当初の見立ては、2級〜1級のレンジとして妥当。

### 1-3. 申請の具体的な流れ

1. 年金事務所（市川なら市川年金事務所）で「年金請求の相談」をする
   - このとき**初診日の証明**（受診状況等証明書＝カルテがある病院に書いてもらう書類）を取れるか確認
   - 保険料納付要件を年金事務所の記録（ねんきん定期便・ねんきんネットでも確認可）で照合
2. 診断書（精神の障害用・眼の障害用、それぞれの様式がある）を主治医に書いてもらう
3. 病歴・就労状況等申立書（本人が書く、事件の経緯や生活状況を時系列でまとめる書類）を作成
4. 年金請求書一式を年金事務所に提出 → 審査（数ヶ月かかる）

### 1-4. 次の一歩（相談支援専門員に確認すること・再掲）

以下は相談支援専門員にそのまま聞ける形にしてある。

```
①障害福祉サービスの受給者証は今持っていますか？
②今、知り合いと進めている申請は「障害者手帳」と「障害年金」のどちらですか？
　両方同時に進めていますか、それとも片方だけ終わっていますか？
③精神科にかかった一番最初の日（初診日）はいつで、
　どの病院にかかっていたか記録に残っていますか？
```

- ①②③がわかった時点で、年金事務所（または社労士）に相談を1本入れる、が次のアクション
- 障害者手帳（精神保健福祉手帳）と障害年金は**別申請**。手帳の診断書を年金の初診日証明に
  流用できる場合もあるので、どちらが先に進んでいるかで動き方が変わる
- 費用がネックなら、社労士に頼まず年金事務所の窓口で無料相談しながら自分で申請することも可能
  （時間はかかるが金はかからない）

## 2. 求職者支援制度（職業訓練受講給付金）

### 2-1. 数字面の要件

- 本人収入：月8万円以下（シフト制勤務等は月12万円以下）
- 世帯全体の収入：月25万円以下
- 世帯全体の金融資産：300万円以下
- 現住所以外に土地・建物を持っていない
- 訓練は原則全日程出席（やむを得ない理由でも8割以上）
- 過去6年以内に同給付金の受給歴がない、世帯内に同時受給者がいない

→ 市川の家は住民票だけで実際は古田君宅に住んでいる状態だが、審査は住民票ベースの
「世帯」で見られるのが基本。市川の家がグループホーム（家賃・光熱費ゼロ、単身世帯）なので
世帯収入の壁はクリアしやすい、という当初の見立ては妥当。

### 2-2. LLMO事業との衝突ポイント（要ハローワーク確認）

- この制度は建前上「再就職を目指す人」向け。ハローワークで求職申込をして、
  職業相談・訓練に原則専念する姿勢が前提
- 個人事業（LLMO）の収入は「本人収入」としてカウントされる → 月8万円以下に
  収まっている必要がある（今は低所得・申告前なので数字上は該当しやすい）
- ただし「自営業を継続しながら求職者支援を受けられるか」は、ハローワークの窓口判断が
  絡む部分で、ネット上に確定した基準は出てこなかった。**ここは【未確認】**。
  市川のハローワークで「個人事業をやりながらの受給可否」を直接聞くのが一番早い

## 3. 自立支援医療（精神通院医療）

- 申請先：住民票がある市川市の担当窓口（障害福祉の窓口）
- 必要書類：申請書、診断書（または精神保健福祉手帳の写しがあれば診断書省略可）、
  マイナンバー確認書類、健康保険証
- 精神保健福祉手帳の新規申請と同時に出す場合、手帳用の診断書1枚で両方の申請ができる
  → 手帳の申請が進んでいるなら、自立支援医療も同時に乗せるのが効率的
- 通院・薬代が原則1割負担になる。審査は障害年金より軽いので、先に通しておいて損はない

## 4. 障害者手帳が出た場合の芋づる

- 手帳（精神保健福祉手帳）が交付されると：
  - 携帯電話の障害者割引（各キャリアにあり）
  - 公共交通機関の運賃割引（自治体・事業者による）
  - NHK受信料の減免（世帯全員が住民税非課税等の条件あり）
  - 所得税・住民税の障害者控除
- ここは手帳が出てから個別に手続きすればいい話なので、今は「年金・手帳どっちが先に
  進んでいるか」の確認が先

## 5. 弟の盤面（沖縄県宜野湾市・介護士）

### 5-1. 処遇改善加算（2026年6月臨時改定）

- 2026年6月の臨時改定で、介護職員だけでなく介護支援専門員（ケアマネ）等にも
  対象が拡大され、月1万円相当（3.3%相当）の賃上げ効果を狙った改定
- 訪問看護・訪問リハビリ・居宅介護支援も新たに加算対象に追加
- → 弟に確認すべきは「6月分以降の給与明細に、処遇改善加算分の増額が反映されているか」。
  事業所が加算を取っていても、個人の給与に反映するタイミングは事業所次第（賞与でまとめて、
  というケースもある）ので、明細を実際に見て確認するのが一番確実

### 5-2. 教育訓練給付

- 介護福祉士実務者研修：一般教育訓練給付金の対象（受講料の一部が戻る）
- 介護支援専門員（ケアマネ）実務研修：特定一般教育訓練給付金の対象
- 専門実践教育訓練給付の対象講座なら受講料の最大80%が戻る枠もある
- 雇用保険の被保険者期間が要件（弟は3年弱＋出戻り分あるので条件は満たしやすい見込み）
- → ハローワーク沖縄（宜野湾管轄）で「対象講座リスト」と「弟の被保険者期間で
  受給資格があるか」を確認するのが次の一歩

### 5-3. ふるさと納税

- 年収240万円・独身のケースでの控除上限は、年収200万円（目安1.5万円）と
  年収300万円（目安2.8万円）の間になるはずで、**2万円前後が目安**（【概算】、
  各サイトのシミュレーターで実際の年収・社会保険料控除額を入れて再計算が必要）
- 実質2,000円の自己負担で返礼品がもらえる制度なので、優先度は低いが手間も小さい

### 5-4. iDeCo

- 節税効果はあるが60歳まで引き出せない。生活防衛資金が貯まってから少額で始める、
  という当初の位置づけのままでいい

### 5-5. 家賃補助

- 宜野湾市の「住居確保給付金」は**離職・廃業した人向け**（単身世帯で月32,000円、
  最長9ヶ月）。弟は現職継続中なので対象外
- 沖縄県が介護分野向けに用意している宿舎借り上げ支援は、調べた範囲では
  **外国人介護人材向け**（月上限3万円）のもので、日本人職員向けの一般的な
  家賃補助制度は見つからなかった
- → この項目は「今のところ使える制度なし」と判断していい。優先度は最下位のままでOK
